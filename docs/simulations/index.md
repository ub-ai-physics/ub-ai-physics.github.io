# Simulations

Interactive web pages that show a physical effect. Each simulation lives in its own folder under `docs/simulations/`, with an `index.html` file inside.

| Simulation | Topic | Year | Author | Status |
|---|---|---|---|---|
| [Simple pendulum (example)](pendulum/index.html){target=_blank} | Mechanics | 1 | Example | draft |

!!! tip "Adding a simulation"
    Ask Claude to make the page as **a single HTML file** with everything inside (no separate files), then upload it as `docs/simulations/your-topic/index.html` and add a line to the table above. See [Contribute](../contribute.md).
