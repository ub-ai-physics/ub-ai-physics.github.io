# UB AI Physics

Physics teaching material made by volunteer physics students at the University of Barcelona, using Claude: lecture notes, interactive simulations and solved problems.

The website is at **https://ub-ai-physics.github.io**. It is rebuilt automatically every time a change is merged into `main`.

How to add your work: see [docs/contribute.md](docs/contribute.md), or the **Contribute** page on the website.

To preview the site on your own computer: `pip install -r requirements.txt`, then `mkdocs serve`.
