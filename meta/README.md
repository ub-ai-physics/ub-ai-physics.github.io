# Carpeta `meta/`

Documents interns de l'equip. No formen part de la web, però el repositori és visible a GitHub:
no hi poseu res que no pugui ser públic.

| Fitxer | Per a què serveix |
|---|---|
| `estat-del-projecte.md` | Qui fa què, tasques obertes i decisions. **Es manté al dia.** |
| `organitzacio.md` | Rols, flux de validació, Drive, tauler i canals. |
| `estructura.md` | Com està feta la web: dades, fitxes d'assignatura i carpetes. |
| `guia-estil.md` | Idioma, format de simulacions, preguntes i guies. |
| `instruccions-projecte-claude.md` | Què posar al projecte compartit de Claude. |

Quan es modifiqui algun d'aquests fitxers, la coordinació el torna a pujar al projecte de Claude.
